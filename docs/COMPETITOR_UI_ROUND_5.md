# Competitor UI study — round 5

Reviewed 2 October 2026 after testing the previous dashboard in the running application.

## What failed in the previous version

The large navy gradient, separate activity card and repeated rounded metric cards made the page feel like a presentation template. It used too much vertical space before the student reached the actual mailbox controls, and the visual weight of the hero competed with the review action.

## References revisited

- **Shortwave:** source, assistant state and next action share one quiet workspace.
- **Notion Calendar:** neutral canvas, thin dividers and restrained colour keep dense schedules readable.
- **MyStudyLife:** the first view is organised around today's work and the next deadline.
- **Superhuman:** compact state indicators reveal what needs attention without filling the page with dashboard widgets.

## Decisions applied

1. Use a warm off-white canvas, white surfaces and charcoal type.
2. Replace the dark sidebar with a quiet white navigation and settings area.
3. Remove the gradient hero, decorative glow and heavy shadows.
4. Present today's decision and agent activity as one bordered workspace.
5. Turn the three summary cards into a single compact information strip.
6. Use one forest-green accent for selection, status and primary actions.
7. Replace large pill navigation with a thin underline tab system.
8. Reduce corner radius and spacing so the working controls appear sooner.
9. Retain the persistent question-mark help button and contextual tooltips.

The redesign changes presentation only. Mailbox filtering, extraction, merging, evidence retention and calendar approval behaviour are unchanged.
