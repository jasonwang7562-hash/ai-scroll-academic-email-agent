# Recorded Demo Plan

## Scene 1  Problem and input

Introduce Jason and show selected academic emails entering the system.

## Scene 2  Extraction with evidence

Show course, task, deadline, urgency, and the exact supporting sentence.

## Scene 3  Cross-email update

Show an original instruction and a later deadline correction becoming one timeline item.

## Scene 4  Safe action

Show the calendar preview. Demonstrate that nothing is written before approval, then approve one event.

## Scene 5  Evidence of quality

Show the baseline comparison, six component counts, one failure or abstention case, and measured cost per item.

## Recording rule

Use a frozen sample path that has already been rehearsed. Keep raw API keys, private email addresses, and personal email text out of the recording.
