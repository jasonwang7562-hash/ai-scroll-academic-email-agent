# Competitor UI study — submission polish

Reviewed 3 October 2026. The previous flat workspace was visually clear but too plain and form-like. The submission design uses one recognisable focus card instead of a completely flat dashboard.

## Selected direction

- **Shortwave:** product-like email workspace and a clear current action.
- **Notion Calendar:** light canvas, restrained spacing and compact navigation.
- **AI Scroll first prototype:** one prominent gradient card that gives the page a memorable visual centre.

## Applied changes

1. Restore one blue-to-teal Today card with strong contrast and a single headline.
2. Keep Agent activity in a separate white card with a visible safety state.
3. Use three compact summary cards for deadline, course scope and review queue.
4. Turn the main navigation into a contained pill bar with a clear active tab.
5. Use soft depth, larger radii and a pale blue canvas while avoiding repeated heavy shadows.
6. Open the submission prototype in Demo mode so the experience works immediately without OAuth.
7. Keep real Gmail, Outlook and Google Calendar connection paths available for later integration.

The result keeps the first prototype's strongest visual element while preserving the clearer workflow and safety explanations added in later rounds.
